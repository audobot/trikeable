# Trikeable

Route planner for wide e-trikes (built around an Addmotor Soletri, 83cm wide). Finds bike routes around Melbourne with no steps, no walk-your-bike sections, and no trike-trapping barriers like swing-gate chicanes, stiles and motorbike A-frames.

- Routing: [BRouter](https://brouter.de) with the custom profile in `soletri.brf`
- Search: [Photon](https://photon.komoot.io)
- Maps: © OpenStreetMap contributors, CyclOSM

Routes can only avoid barriers that are mapped in OpenStreetMap.
